# Практикум: Тестирование класса Burger

## Описание проекта

Написание модульных тестов для класса `Burger` в Java-приложении `praktikum`. Бургер состоит из булочки (`Bun`) и списка ингредиентов (`Ingredient`), которые могут быть соусами (`SAUCE`) или начинками (`FILLING`). Класс `Burger` позволяет:

- устанавливать булочку;
- добавлять, удалять и перемещать ингредиенты;
- рассчитывать итоговую цену;
- формировать чек с информацией о бургере.

## Цель исследования

Проверить корректность работы методов класса `Burger`, включая граничные случаи, с помощью unit-тестов. Убедиться, что:

- цена рассчитывается правильно при различных комбинациях цен;
- ингредиенты корректно добавляются, удаляются и перемещаются;
- чек формируется в ожидаемом формате;
- некорректные индексы вызывают исключения.

## Исследуемый набор данных

Отдельного набора данных для анализа нет. В качестве тестовых данных используются:

- предопределённые объекты из класса `Database` (булочки и ингредиенты);
- моки и стабы, создаваемые через Mockito, с заданными ценами, именами и типами.

Это позволяет изолировать тестируемый класс и проверять его поведение независимо от реальных данных.

## Основные пункты

- Написание unit-тестов с использованием моков (Mockito) для изоляции `Burger`.
- Применение параметризации (JUnit Parameterized) для проверки расчёта цены при разных входных данных.
- Разделение тестов: один тест — одна проверка.
- Устранение магических чисел через именованные константы.
- Проверка формата чека и наличия обязательных строк.
- Тестирование исключений при некорректных индексах.

## Используемые библиотеки и инструменты

- **Java 11** — язык разработки.
- **JUnit 4** — фреймворк для модульного тестирования.
- **Mockito** — создание моков и стабов.
- **Maven** — сборка проекта и управление зависимостями.
- **JaCoCo** — измерение покрытия кода тестами.
